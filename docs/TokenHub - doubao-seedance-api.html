Doubao Seedance 视频生成 API 文档

火山方舟（Ark）Seedance 系列

概述

网关支持火山方舟（Ark）Seedance 系列视频生成模型（doubao-seedance-2-0-260128、doubao-seedance-2-0-fast-260128、doubao-seedance-2-0-mini-260615），采用 创建任务 → 轮询结果 的异步调用模式。

模型列表

模型名称 类型 说明
doubao-seedance-2-0-260128 标准版 豆包 Seedance 2.0 标准视频生成模型
doubao-seedance-2-0-fast-260128 快速版 快速视频生成，推理速度更快
doubao-seedance-2-0-mini-260615 Mini 版 轻量化模型，适合简单任务

调用流程

视频生成采用异步任务模式，分两步完成：

  1. 提交任务：调用 POST /v1/videos/generations，返回任务 ID（output.task_id）
  2. 轮询结果：调用 GET /v1/videos/generations/task/{taskId} 查询状态

状态流转：

running → succeeded / failed

一、提交视频生成任务

1.1 请求地址

HTTPPOST /v1/videos/generations

1.2 请求头

Header 必填 说明
Content-Type 是 固定为 application/json
Authorization 是 格式：Bearer <your-api-key>
Seedance 系列无需设置 X-DashScope-Async 请求头。

1.3 请求参数

顶层参数

参数名 类型 必填 说明
model string 是 模型名称：doubao-seedance-2-0-260128 / doubao-seedance-2-0-fast-260128 / doubao-seedance-2-0-mini-260615
content array[object] 是 素材与提示词混合数组。最少 1 个元素，支持 text / image_url / video_url / audio_url 四种类型
generate_audio bool 否 自动生成配音。仅画面无需音频时传 false。默认 true
ratio string 否 宽高比：9:16 / 16:9 / 1:1。默认 16:9
duration int 否 生成视频总时长（秒）
watermark bool 否 是否添加平台水印。默认 false

content 元素类型

1. 文本提示词 (type = text)

参数名 类型 必填 说明
type string 是 text
text string 是 分镜文案。用 [Image N] / [Video N] / [Audio N] 引用素材

2. 参考图片 (type = image_url)

参数名 类型 必填 说明
type string 是 image_url
image_url.url string 是 图片 URL（HTTP/HTTPS 或 Base64）
role string 是 reference_image

3. 参考视频 (type = video_url)

参数名 类型 必填 说明
type string 是 video_url
video_url.url string 是 公网可访问 MP4 视频链接
role string 是 reference_video

4. 参考音频 (type = audio_url)

参数名 类型 必填 说明
type string 是 audio_url
audio_url.url string 是 公网可访问 MP3 音频链接
role string 是 reference_audio
约束说明：参考图片最多 9 张 · 参考视频最多 1 个 · 参考音频最多 1 个 · 纯文生视频仅需 1 个 type: "text" 元素

三、素材管理接口（通用约定）

视频生成常需引用已上传的参考图片/视频/音频。网关提供素材库能力，对素材组（AssetGroup）和素材（Asset）做 CRUD，统一中转到火山素材库上游。

3.1 统一入口

HTTPPOST /v1/api/asset?Action=<Action>&Version=2024-01-01
  • Action 决定具体接口，Version 固定 2024-01-01
  • 全部 POST 方法，Content-Type: application/json
  • 鉴权：Authorization: Bearer <your-api-key>（必填）
  • 请求体字段名 PascalCase（如 Name、GroupId、Filter.GroupIds）

3.2 Action 列表速览

Action说明章节
CreateAssetGroup创建素材组四.1
ListAssetGroups列出素材组四.2
GetAssetGroup查询单个素材组四.3
UpdateAssetGroup更新素材组四.4
DeleteAssetGroup删除素材组四.5
CreateAsset创建素材五.1
ListAssets列出素材五.2
GetAsset查询单个素材五.3
UpdateAsset更新素材五.4
DeleteAsset删除素材五.5
私有隔离：所有查询/更新/删除带 key 归属过滤，只能操作自己 key 下的组与素材。越权访问或资源不存在统一返回 404（不区分两者）。

六、视频生成中的 asset:// 引用

视频生成接口 POST /v1/videos/generations 的 content 数组里，可用 asset://<Id> 引用已创建的素材替代公网 URL。网关在转发上游前自动校验所有 asset:// 引用是否归属当前 Authorization key，不属于则 fail-closed 返回 403。

6.1 三种引用写法

JSON// 图片引用（role: reference_image / first_frame / last_frame）
{"type":"image_url","role":"reference_image","image_url":{"url":"asset://182533555060998168"}}

// 视频引用（role: reference_video）
{"type":"video_url","role":"reference_video","video_url":{"url":"asset://<Id>"}}

// 音频引用（role: reference_audio）
{"type":"audio_url","role":"reference_audio","audio_url":{"url":"asset://<Id>"}}

6.2 归属校验行为

场景结果
引用自己 key 下的 Active 素材200 放行，正常生成 task_id
引用他人 key 下的素材403 asset not owned by key: [...]
一次请求引用了多个不同 provider 的素材403 assets from multiple providers in one request
content 里无 asset:// 引用（纯文生视频/公网 URL）200 不校验，直接放行
归属校验服务不可用/超时403 fail-closed

6.3 端到端示例（建组 → 建素材 → 轮询 Active → 视频生成）

BashGATEWAY="http://<gateway-host>"
API_KEY="<your-api-key>"

# 1. 创建素材组
GROUP_ID=$(curl -s -X POST "${GATEWAY}/v1/api/asset?Action=CreateAssetGroup&Version=2024-01-01" \
  -H "Content-Type: application/json" -H "Authorization: Bearer ${API_KEY}" \
  -d '{"Name":"视频素材组","GroupType":"AIGC"}' | jq -r '.Id')
echo "组 ID: ${GROUP_ID}"

# 2. 创建素材（图片）
ASSET_ID=$(curl -s -X POST "${GATEWAY}/v1/api/asset?Action=CreateAsset&Version=2024-01-01" \
  -H "Content-Type: application/json" -H "Authorization: Bearer ${API_KEY}" \
  -d "{\"GroupId\":\"${GROUP_ID}\",\"URL\":\"https://example.com/cat.jpg\",\"AssetType\":\"Image\",\"Name\":\"猫咪\"}" \
  | jq -r '.Id')
echo "素材 ID: ${ASSET_ID}"

# 3. 轮询素材就绪（Status=Active）
while true; do
  STATUS=$(curl -s -X POST "${GATEWAY}/v1/api/asset?Action=GetAsset&Version=2024-01-01" \
    -H "Content-Type: application/json" -H "Authorization: Bearer ${API_KEY}" \
    -d "{\"Id\":\"${ASSET_ID}\"}" | jq -r '.Status')
  echo "素材状态: ${STATUS}"
  [ "${STATUS}" = "Active" ] && break
  sleep 5
done

# 4. 提交视频生成任务，用 asset:// 引用素材
TASK_ID=$(curl -s -X POST "${GATEWAY}/v1/videos/generations" \
  -H "Content-Type: application/json" -H "Authorization: Bearer ${API_KEY}" \

  | jq -r '.output.task_id')

# 5. 轮询视频生成结果
while true; do

    -H "Authorization: Bearer ${API_KEY}")

  echo "任务状态: ${STATUS}"
  if [ "${STATUS}" = "succeeded" ]; then
    echo "视频 URL: $(echo "${RESULT}" | jq -r '.content.video_url')"
    break
  elif [ "${STATUS}" = "failed" ]; then
    echo "失败: $(echo "${RESULT}" | jq -r '.error.message')"
    break
  fi
  sleep 10
done

九、注意事项

有效期限制：task_id 及视频下载 URL 有效期为 24 小时，请及时下载。
轮询间隔：建议 5–15 秒轮询一次，避免过于频繁。
无需 X-DashScope-Async 头：Seedance 系列使用 task-based 端点，不需要此请求头。
素材引用规则：在 type: "text" 中，按 content 数组顺序从 1 开始编号，使用 [Image N] / [Video N] / [Audio N] 引用对应素材。
素材 URL 有效期：GetAsset / ListAssets 返回的 URL 由上游签发，约 12 小时失效，需及时使用。
素材就绪才可引用：仅 Status=Active 的素材可用于视频 asset:// 引用；创建后通常需轮询 5–30 秒等待 Processing → Active。
跨 key 引用禁止：asset:// 引用他人 key 下的素材会被 fail-closed 拦截返回 403。
私有隔离：素材组/素材的查询、更新、删除均带 key 归属过滤，越权访问与资源不存在统一返回 404。
